# Smart Library Management Website (Fixed Static Version)

This ZIP contains a responsive, four-page Library Management student project:
- `index.html` — Home
- `books.html` — searchable book catalogue with category filter
- `services.html` — demo issue/return form
- `contact.html` — demo contact form
- `css/style.css` — responsive styling
- `js/app.js` — navigation, search, and client-side form validation

## Run on your computer
Extract the ZIP and open `index.html` in a browser. No installation is required.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload the CONTENTS of this folder (not the outer folder) to the repository root.
4. Ensure `index.html` is at the top level beside `books.html`, `services.html`, and `contact.html`.
5. Commit the changes.
6. Open Settings → Pages. Select branch `main` and folder `/(root)` if that matches your repository setup.
7. Wait for deployment, then refresh the published site.

## Important
This is a front-end demonstration. The issue/return and contact forms only show a confirmation in the browser; they do not save records or send email. Real login, database storage, and book issue records need a backend.
